    What is a JWT Bearer Token?

    Discover how Saraha protects your identity and secures private inbox requests using JSON Web Tokens (JWT) and HTTP Bearer headers.

    1. Header (Algorithm & Type)

    Specifies the hashing algorithm used to sign the token (e.g. HS256) and the token type (JWT).

    2. Payload (User Claims)

    Contains non-sensitive identity claims such as user ID, issued timestamp (iat), and expiration (exp).

    3. Signature (HMAC Security)

    Generated using the secret key on the server (`JWT_SECRET`). Guarantees the token cannot be tampered with.
